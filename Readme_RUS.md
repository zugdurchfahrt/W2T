# W2T (экспорт чатов WhatsApp в Telegram)

Утилита для экспорта чатов из WhatsApp (включая все медиафайлы) напрямую в Telegram через официальное MTProto API.

В отличие от ботов и пересылки сообщений, этот скрипт использует нативный метод Telegram `InitHistoryImportRequest`. Благодаря этому вся история импортируется с **оригинальными датами и временем**, сохраняя вид естественной переписки.

## Возможности
- Поддержка импорта как **личных чатов**, так и **групповых чатов**.
- Валидация типа экспортируемого файла перед загрузкой (личный / групповой).
- Сохранение оригинальных таймстампов (дат и времени) сообщений.
- Загрузка и привязка всех медиафайлов — картинки, видео, аудио, документы (PDF, Word, Excel, PowerPoint и др.).
- Отображение размера каждого файла при загрузке.
- Запрос подтверждения перед началом импорта для предотвращения случайной загрузки не в тот чат.
- Автоматическое преобразование обычных групп Telegram в Супергруппы при необходимости.
- Корректная обработка ошибок соединения, Anti-Flood ограничений и сетевых сбоев при загрузке медиафайлов.
- Корректное закрытие сессии Telegram при выходе.

## Установка (Для разработчиков)

## Требования
- Python 3.8+
- [Telethon](https://github.com/LonamiWebs/Telethon) (устанавливается автоматически через `requirements.txt`)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/w2t.git
   cd w2t
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получите ваши **API ID** и **API Hash** на сайте [my.telegram.org](https://my.telegram.org/auth).

## Использование
1. Экспортируйте нужный чат из WhatsApp (с медиафайлами, без ограничения размера) в виде `.zip` архива и перенесите на компьютер.
2. Распакуйте архив в отдельную папку.
3. **Если вы импортируете чат в группу**: создайте новую чистую группу в Telegram и **обязательно добавьте в неё всех участников до начала импорта**. Telegram ограничивает видимость импортированных сообщений только для тех участников, которые были в группе на момент импорта.
4. Запустите исполняемый файл (`w2t.exe`) или Python-скрипт:
   ```bash
   python main.py
   ```
   *(Можно также передать аргументы через CLI: `python main.py --api-id ВАШ_API_ID --api-hash ВАШ_API_HASH --export-dir /путь`)*
5. Следуйте интерактивным подсказкам:
   - **Шаг 1**: Выберите тип импорта (Личный чат или Групповой чат).
   - Укажите путь к распакованной папке экспорта WhatsApp.
   - **Шаг 2**: Выберите целевой диалог Telegram из полного списка ваших чатов.
   - Подтвердите импорт при появлении запроса.
6. Дождитесь окончания загрузки.

## Как это работает
1. Скрипт считывает текстовый файл `.txt` из экспорта WhatsApp и отправляет первые 2000 символов в `CheckHistoryImportRequest` Telegram для определения типа чата (личный или групповой).
2. Скрипт проверяет, что обнаруженный тип чата совпадает с вашим выбором. При несовпадении работа прекращается с сообщением об ошибке.
3. После выбора целевого диалога и подтверждения скрипт загружает текстовый файл, а затем каждый медиафайл, упомянутый в логе чата.
4. В завершение вызывается `StartHistoryImportRequest` для финализации импорта на стороне Telegram.

## Важно
Telegram ограничивает видимость импортированных сообщений для тех, кто вступил в чат **после** импорта. Обязательно добавляйте всех нужных людей в группу до запуска утилиты.

## Решение проблем
| Проблема | Решение |
|---|---|
| `ConnectionError` при запуске | Возможно, вы находитесь в регионе с ограниченным доступом к Telegram. Включите VPN. |
| `IncompleteReadError (0 bytes read)` | Ваша сессия была аннулирована или сработал Anti-Flood Telegram. Смените VPN-сервер и подождите перед повторной попыткой. |
| `IMPORT_PEER_TYPE_INVALID` | Несовпадение типа чата. Убедитесь, что вы выбрали правильный тип импорта (Личный / Групповой). |
| Медиафайлы не найдены | Убедитесь, что медиафайлы находятся в той же папке, что и `.txt` файл, и их имена совпадают с указанными в логе. |
| Консоль «зависает» при вводе пароля | Это ожидаемое поведение. Когда Telegram запрашивает пароль двухфакторной аутентификации, консоль намеренно скрывает ввод — символы не отображаются на экране. Просто введите пароль и нажмите Enter: ввод производится, несмотря на внешнюю «заморозку». |
