# w2t (WhatsApp в Telegram)

Утилита на Python (CLI) для бесшовного переноса экспортированных чатов из WhatsApp (включая медиафайлы) напрямую в Telegram через официальное MTProto API.

В отличие от ботов и пересылки сообщений, этот скрипт использует нативный метод Telegram \InitHistoryImportRequest\. Благодаря этому вся история импортируется с **оригинальными датами и временем**, сохраняя вид естественной переписки.

## Возможности
- Сохранение оригинальных таймстампов (дат и времени) сообщений.
- Загрузка и привязка всех медиафайлов (картинки, видео, аудио).
- Автоматическое преобразование обычных групп Telegram в Супергруппы для поддержки импорта.
- Устойчивость к обрывам связи при загрузке больших файлов.

## Требования
- Python 3.8+
- \	elethon
## Установка
1. Склонируйте репозиторий:
   \\ash
   git clone https://github.com/your-username/w2t.git
   cd w2t
   \2. Установите зависимости:
   \\ash
   pip install -r requirements.txt
   \3. Получите ваши **API ID** и **API Hash** на сайте [my.telegram.org](https://my.telegram.org/auth).

## Использование
1. Экспортируйте нужный чат из WhatsApp (вместе с медиафайлами) в виде \.zip\ архива и перенесите на компьютер.
2. Распакуйте архив в отдельную папку.
3. Если вы импортируете чат в группу, создайте новую чистую группу в Telegram и **обязательно добавьте в неё всех участников до начала импорта** (это требование приватности Telegram, чтобы они видели сообщения).
4. Запустите скрипт:
   \\ash
   python w2t.py --api-id ВАШ_API_ID --api-hash ВАШ_API_HASH --export-dir /путь/к/распакованной/папке
   \5. Скрипт запросит ваш номер телефона и код авторизации от Telegram.
6. Выберите нужный чат из списка ваших недавних диалогов.
7. Дождитесь окончания загрузки!

## Важно
Telegram ограничивает видимость импортированных сообщений для тех, кто вступил в чат *после* импорта. Обязательно добавляйте всех нужных людей в группу до запуска утилиты.
